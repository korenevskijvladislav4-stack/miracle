# MIRACLE GLOW — боты розыгрыша

Один процесс запускает админ-бота и всех ботов розыгрыша (по одному на канал/пул).
Общая база SQLite гарантирует: один Telegram ID участвует только в одном пуле.

## Запуск

1. Создайте админ-бота в @BotFather и скопируйте `.env.example` в `.env`:
   - `ADMIN_BOT_TOKEN` — токен админ-бота;
   - `ADMIN_IDS` — Telegram ID администраторов через запятую
     (свой ID админ-бот покажет в ответ на любое сообщение, если доступа нет).
2. Установите зависимости и запустите:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Админка (в админ-боте, команда /admin)

- **Статистика** — участники по пулам, прирост за 24 ч, сколько нажали Start, конверсия, отписавшиеся.
- **Боты** — создать бота (код пула → токен → язык → канал → ссылка), включить/выключить,
  сменить язык или канал, удалить. Новый бот начинает работать сразу, без перезапуска.
  У каждого бота один язык: пользователь язык не выбирает.
- **Тексты и языки** — правка любой фразы и кнопки на любом языке, сброс к стандартной, добавление/удаление языков.
- **Экспорт** — CSV по пулу или по всем пулам.
- **Перепроверить подписки** — обновляет статус подписки участников (например, перед розыгрышем).

Каждый бот розыгрыша должен быть **администратором своего канала** — иначе Telegram
не даёт проверять подписку.

## Сценарий участника

Start → «Подписаться» / «Проверить подписку» → регистрация
(`telegram_id + source_channel`). Если пользователь уже участвует (в этом или другом боте),
он получает «Ты уже участвуешь в MIRACLE GLOW».
